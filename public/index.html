Upload CSV File

Browser bulk is capped (default 50 unique emails, 2 MiB). For large lists, use the self-hosted MCP verify_csv tool. Result downloads sanitize formula-like cells.

CSV Format Requirements

  • File must be in .csv format (UTF-8).
  • The first row must contain the email column header.
  • Recommended column name: Email (case-insensitive; also accepts email, e-mail, email_address, mail).
  • Each subsequent row should contain one email address.
  • Additional columns are allowed; the email column is detected automatically.
  • Empty rows are skipped. Invalid email values are validated and shown in results — not silently discarded.

Example:

Email
john@example.com
alice@example.com
support@example.org

FAQ

Does MailSure prove an inbox exists?

No. Results are domain-level and policy signals. Never treat valid_domain as mailbox proof.

Why is verify disabled on GitHub Pages?

Pages serves static files only. Point API_BASE_URL at a self-hosted server with the website API enabled, or use MCP locally. We never invent results.

Is this free?

Yes — open-source under GPL-3.0. See pricing for the transparent free model.

Where is the MCP server?

In this repository: eneelkant/email-validation-tool.
