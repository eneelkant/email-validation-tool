MailSure

Email Verification Made Simple.

Check syntax, domain DNS/MX, disposable domains, and role-based addresses — free, open-source, and self-hosted. Domain signals only; we never claim a mailbox exists.

Results mirror the OpenVerify ValidationResult schema.

Browser bulk is capped (default 50 unique emails, 2 MiB). For large lists, use the self-hosted MCP verify_csv tool. Downloads sanitize formula-like cells.

Features

Built on the OpenVerify MCP validation engine — the same checks your agents use.

Syntax & IDN

RFC-aware syntax validation with internationalized domain support.

DNS / MX

Domain existence and mail-exchanger lookups with timeouts treated as temporary, not invalid.

Disposable & role

Local disposable-domain dataset and configurable role-based local parts.

Bulk CSV

Browser-friendly batches here; streaming, bounded MCP CSV jobs for large files.

MCP-native

STDIO and Streamable HTTP for Cursor, Claude, Gemini CLI, and more.

No paid credits

Self-host the engine. No commercial verification API dependency.

Important: valid_domain means the domain looks mail-capable. It does not mean the individual mailbox was confirmed.

FAQ

Does MailSure prove an inbox exists?

No. Results are domain-level and policy signals. Never treat valid_domain as mailbox proof.

Why is verify disabled on GitHub Pages?

Pages serves static files only. Point API_BASE_URL at a self-hosted server with the website API enabled, or use MCP locally. We never invent results.

Is this free?

Yes — open-source under GPL-3.0. See pricing for the transparent free model.

Where is the MCP server?

In this repository: eneelkant/email-validation-tool.
