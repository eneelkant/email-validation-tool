Privacy Policy

Draft for legal review. Not legal advice.

Draft — for legal review. This document is a placeholder describing intended practices for the static MailSure site and optional self-hosted API. Have counsel review before relying on it.

1. Scope

This draft covers the public static website hosted on GitHub Pages and any self-hosted OpenVerify website API you operate. Self-hosted deployments are under your control and privacy obligations.

2. Data you may submit

If you configure a backend and submit email addresses for verification, those addresses are processed to perform DNS and related checks. The static GitHub Pages build does not include a backend and will not process submissions until you point it at a server you control.

3. Logs and secrets

The OpenVerify engine redacts email addresses from logs by default (OPENVERIFY_LOG_EMAILS=false). Do not place API tokens or secrets in frontend code. MCP admin tools are not exposed through the website API.

4. Cookies and analytics

This static site does not ship third-party analytics or tracking cookies in the default build. GitHub Pages and your browser may still produce standard access logs outside this project’s control.

5. Third parties

Fonts may load from Google Fonts when online. DNS lookups performed by a self-hosted backend query public DNS infrastructure as part of verification.

6. Contact

Use GitHub issues for project questions. See Contact. Security reports: follow SECURITY.md.

7. Changes

Updates to this draft will be committed to the repository. Replace this draft after legal review.
